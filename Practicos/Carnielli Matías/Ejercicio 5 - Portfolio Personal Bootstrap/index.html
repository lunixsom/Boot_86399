E-Commerce Platform

Desarrollé una plataforma de e-commerce completa desde cero utilizando el stack MERN. La aplicación incluye un sistema de autenticación robusto, carrito de compras persistente, integración con Stripe para pagos seguros, y un panel de administración completo para gestionar productos, órdenes y usuarios.

Características principales:

  • Autenticación de usuarios con JWT
  • Carrito de compras con persistencia en base de datos
  • Pasarela de pagos Stripe integrada
  • Panel de administración completo
  • Sistema de búsqueda y filtros avanzados
  • Diseño responsive y accesible

Weather Dashboard

Dashboard meteorológico interactivo que consume datos de la API de OpenWeather. Incluye visualización de datos con gráficos, mapas interactivos, y sistema de alertas para condiciones climáticas específicas. El proyecto demuestra habilidades en consumo de APIs, visualización de datos y diseño responsive.

Características principales:

  • Pronóstico extendido de 7 días
  • Datos en tiempo real de múltiples ciudades
  • Gráficos interactivos con Chart.js
  • Mapas de temperatura y precipitación
  • Sistema de alertas personalizables
  • Búsqueda por ubicación
JavaScript OpenWeather API Chart.js Vanilla JS
